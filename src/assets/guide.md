## 书架

书架是书籍管理的主界面，所有已添加的书籍以封面网格的形式展示于此。

### 添加书籍

**导入 TXT**

点击右上角"导入 TXT"，选择本地的 `.txt` 文件。墨阅会读取文件内容，根据 TXT 目录规则自动识别章节标题并分章。导入成功后作者显示为"本地文件"。

**添加网址**

点击"添加网址"，输入书籍详情页或目录页的完整 URL，然后选择书源。墨阅会根据书源规则获取书名、作者、封面、简介等信息并加入书架。

### 分组管理

书架顶部的分组标签用于分类管理书籍：

- 默认有"全部"和"未分组"两个标签
- 点击 `+` 号创建新分组，输入名称保存
- 右键分组标签可重命名或删除该分组（删除分组不会删除分组内的书籍，书籍会回到未分组状态）
- 右键书籍封面，在菜单中选择目标分组即可移动
- 选择某个分组后，书架只显示该分组下的书籍

### 搜索与刷新

搜索框支持按书名或作者实时筛选，输入即可过滤，无需回车。

"刷新"按钮重新从数据库加载书架数据和书源列表，适用于刚导入书源后需要立即生效的场景。

### 右侧角色互动

书架左下角侧边栏有四个角色，各自有不同的交互行为：

**紫色（大紫）**

点击切换主题，在深色 → 浅色 → 护眼之间循环。点击后会弹出"换个风格？""眼睛舒服吗"等提示气泡。紫色和黑色角色拥有可动的眼珠，会跟随鼠标移动，并随机眨眼。

**黑色（小黑）**

点击随机打开一本当前书架上的书。会弹出"来本随机书！""开盲盒咯~"等提示，约 1.5 秒后自动跳转到书籍详情页。

**橙色（小橙）**

点击循环播报阅读数据。每次点击依次播报：书架书籍总数、今日阅读章节数。如果没有数据，会自嘲"还没有书呢""今天还没读书哦"。

**黄色（小黄）**

点击表演跳舞动画，角色左右摇摆并弹出"来跳舞！""啦啦啦~"等提示。

**通用交互**

- 鼠标悬停时角色放大至 1.1 倍，移开恢复
- 所有角色可拖拽到侧边栏内任意位置，松开后位置自动保存到浏览器本地存储。双击角色可让它回到默认位置
- 长时间不操作时，角色会随机跳一下并自言自语（气泡显示 2.5 秒后自动消失）

## 书籍详情

点击书架上的书籍封面进入详情页。

### 信息展示

- 左侧展示书籍封面图，底部标注书源名称
- 右侧展示书名、作者
- 元数据标签：分类（金色标签）、字数、最新章节（可横向滚动）
- 简介区域可滚动查看，自动去除 HTML 标签，段落首行缩进

### 目录操作

详情页中部为章节目录列表：

- 点击章节标题直接跳转到阅读器并定位到该章节
- 目录顶部有搜索框，输入关键词实时筛选匹配的章节
- 章节超过 200 条时自动分页，使用左右箭头翻页，显示当前页码/总页数
- 上次阅读到的章节会自动定位并高亮显示
- VIP 章节右侧有 `VIP` 徽标

### 底部操作

- **移出**：将当前书籍从书架移除，需确认
- **换源**：弹出对话框，并发搜索所有已启用的书源，匹配同名书籍。点击结果项切换书源，自动重新加载目录
- **登录**：如果书源配置了登录规则，弹出登录窗口。支持 LoginUI（表单式登录）和 URL 直跳登录两种模式
- **加书架**：将书籍加入书架。已在书架时按钮禁用并显示"已在书架"
- **开始阅读 / 继续阅读**：有阅读进度时显示"继续阅读"并从上次位置打开，否则显示"开始阅读"从第一章开始

## 阅读器

### 界面布局

阅读器为全屏模式：顶部标题栏显示当前章节标题和返回按钮，底部为操作工具栏，中间为正文区域。

顶部和底部栏默认 3 秒后自动隐藏。点击正文区域可切换显示/隐藏。鼠标移入工具栏区域暂停自动隐藏，移出后重新计时。

### 翻页与进度

- 键盘左右方向键切换上/下一章
- 底部工具栏的上/下一章按钮
- 底部左侧显示当前章节的滚动进度百分比
- 自定义滚动条（右侧细条）在滚动时显示，1.5 秒后自动隐藏

### 主题切换

底部工具栏的主题按钮：深色（黑底白字）、浅色（白底黑字）、护眼（暖黄底）。当前选中的主题按钮高亮。

### 字体调整

点击 `A-` / `A+` 按钮调整字体大小，范围 12px - 32px，当前值显示在按钮之间。

行间距在"设置 → 阅读"中调整。

### 净化开关

底部工具栏的五角星按钮控制正文净化功能：

- **高亮状态（★）**：净化开启，自动应用所有已启用的替换规则（正则替换、纯文本替换、JS 替换），同时执行段落重排（如果开启）和去除正文开头重复的书名/章节名
- **灰色状态（☆）**：净化关闭，显示原始正文内容

切换净化状态后立即重新处理当前章节，不影响其他章节的净化状态或预加载缓存。预加载的后续章节会根据当前净化开关状态重新处理。

### 划词操作

用鼠标选中正文中的文字后，弹出浮动菜单，包含两个选项：

**复制**

将选中的文字复制到系统剪贴板。

**字典**

打开字典弹窗，使用配置的字典规则查询选中的文字。如果配置了多个已启用的字典规则，弹窗顶部会显示规则标签可切换。切换标签时自动查询对应规则，每个规则的结果独立缓存。

### 字典查询

字典弹窗中，点击结果中的链接会在新窗口打开。查询结果使用 DOMPurify 净化后渲染，保证安全性。

字典规则在"设置 → 字典规则"中配置。

### 漫画模式

当书源的 `bookSourceType` 为 2（漫画）时，阅读器自动切换为漫画模式：

- 图片纵向排列，占满屏幕宽度
- 每张图片独立加载，加载中显示加载动画和页码
- 图片加载失败显示"第 X 页加载失败"，点击可重试
- 图片优先通过后端代理加载（支持多策略降级：裸请求 → 带书源 headers → 完整 headers → 浏览器直连），成功后自动缓存到本地
- 后台预取：当前章节图片加载的同时，异步预取后续章节的图片资源

### 阅读进度

- 每章的滚动百分比自动保存，翻页或退出阅读器时写入数据库
- 今日阅读章节数实时统计（每章只计一次），侧边栏橙色角色可播报
- 下次打开同一本书时自动恢复到上次阅读的章节和位置

## 搜索

### 基本使用

1. 在搜索框输入书名或作者关键词
2. 按回车或点击"搜索"
3. 系统并发搜索所有已启用的书源（默认 5 个并发），进度条实时显示完成数/总数
4. 点击"取消"可终止搜索
5. 结果按书源名称分组，每组显示匹配的书籍数量

### 搜索结果

- 结果以封面网格展示，点击封面进入详情页
- 图片加载失败时自动替换为书名占位封面
- 空结果提示"未找到相关书籍"，建议更换关键词或检查书源是否启用
- 详情页可点击"换源"在其他书源中查找同名书籍

## 发现页

### 基本使用

1. 从顶部下拉框选择一个书源（仅显示已配置 `exploreUrl` 的书源）
2. 下拉框旁有搜索框可筛选书源名称
3. 选择书源后自动加载分类标签
4. 分类标签中的纯文字项为分隔标题，蓝色链接项为可点击的分类
5. 点击分类标签加载书籍列表，滚动到底部自动加载更多（无限滚动）
6. 点击书籍封面进入详情页
7. 加载完所有页面后显示"已加载全部"

### 筛选功能

部分书源支持动态筛选条件，由书源的 `exploreUrl` 规则定义：

**下拉选择（select）**

显示标签名和下拉框，选项由书源规则中的 `chars` 定义。选择后立即触发，如有 `action` 则先执行，然后重新加载当前分类的书籍列表。

**开关切换（toggle）**

显示标签名和当前选项值。点击按钮在 `chars` 数组定义的选项间循环切换。切换后触发 `action`（如有），然后**重新加载整个分类列表**（不仅仅是当前分类的书籍）。

**文本输入（text）**

显示标签名和输入框。输入内容 600ms 防抖后触发 `action`（如有）。

**操作按钮（button）**

显示一个操作按钮，按钮文字优先使用 `viewName`，否则使用 `title`。点击执行 `action`。

**筛选状态持久化**

所有筛选条件的值按书源独立存储，切换书源或重新打开发现页时保留上次的筛选状态。

### 重置筛选

当存在筛选条件时显示"重置筛选"按钮。点击后清空当前书源下所有筛选状态，重新加载分类。

### 日志查看

右上角"日志"按钮打开日志面板，实时显示发现页操作的日志：

- 加载分类的开始和完成
- JS 规则执行的步骤和结果
- 获取书籍列表的数据量
- 错误和异常信息

## 书源管理

### 导入书源

- **粘贴 JSON**：弹窗中粘贴书源 JSON，支持单个对象或数组。自动去重（相同 `bookSourceUrl` 的不重复导入）
- **从 URL**：输入书源 JSON 文件的直链，系统自动下载并导入
- **上传文件**：选择本地的 `.json` 文件

导入过程中显示进度条，完成后自动刷新书源列表。

### 列表操作

- 按分组折叠/展开，每个分组显示包含的书源数量
- 每行显示：复选框、书源名称、分组、启用状态（绿色圆点/灰色圆点）、最近测试结果、操作按钮
- 搜索框支持按书源名称或 URL 筛选
- 分组下拉框支持按分组筛选
- 点击书源名称可查看详情（弹出提示框显示名称和 URL）

**操作按钮**

- **调试**：打开调试面板，可测试该书源的搜索、目录、正文、JS 规则
- **测试**：检测书源 URL 是否可访问，显示响应时间和数据大小
- **启用/禁用**：切换书源启用状态，禁用的书源不参与搜索
- **删除**：移除该书源，需确认

### 批量操作

勾选书源后出现批量操作栏，显示已选数量：

- **批量启用/禁用**：切换选中书源的启用状态
- **反选**：反转当前选择
- **优化**：使用 AST 引擎自动修复选中书源的 JS 代码兼容性问题。`?` 图标悬停可查看优化说明
- **批量删除**：删除选中书源，需确认

### 测试全部与删除失效

**测试全部**：并发检测所有书源的可用性，测试过程中实时显示进度（`测试中 X/N`），完成后弹出提示。

**删除失效**：自动测试所有书源，删除不可访问的书源。操作前弹窗确认。

## 订阅

### 订阅源列表

- 显示订阅源名称、分组标签（金色）、注释、启用/禁用状态（绿色/灰色）
- 支持搜索和分组筛选
- 左侧有复选框，支持多选

**每行操作按钮（从左到右）**

- **打开**：跳转到文章列表
- **编辑**：跳转到编辑页面
- **调试**：跳转到调试页面
- **登录**：如果订阅源配置了登录规则，弹出登录弹窗；否则提示"未配置登录"
- **启用/禁用**：切换订阅源状态，对勾图标为启用，叉图标为禁用
- **删除**：移除该订阅源，需确认

### 批量操作

勾选多个订阅源后出现操作栏：

- **启用/禁用**：批量切换状态
- **置顶/置底**：调整 `customOrder` 值
- **删除**：批量删除，需确认
- **取消选择**：清空勾选

### 导入导出

- **导入 JSON**：弹窗粘贴 JSON
- **导入文件**：选择本地文件
- **恢复默认**：加载内置订阅源（规则订阅、乌云净化），已存在的不重复添加
- **导出**：导出当前所有订阅源为 JSON 文件下载

### 分组管理

弹出窗口中管理分组：

- 添加新分组
- 重命名分组（同步更新所有该分组下的订阅源）
- 删除分组（清空该分组下所有订阅源的分组字段）

### 文章列表

文章列表的显示样式由订阅源的"文章样式"决定：

- **列表**（样式 0）：传统纵向列表，每行显示标题、描述、日期
- **卡片**（样式 1）：大卡片布局，带封面图片
- **网格2列**（样式 2）：两列网格，带封面图片
- **瀑布流**（样式 3）：自适应高度
- **网格3列**（样式 4）：三列网格

如果订阅源配置了 `sortUrl`，文章列表顶部显示排序标签，切换不同分类。

加载更多按钮在列表底部，点击加载下一页。

### 文章阅读

点击文章进入阅读视图。正文提取优先级：订阅源的正文规则 → `<body>` 标签内容。使用 DOMPurify 净化后渲染。

如果文章以 WebView 模式打开（`useWebView: true`），优先使用 WebView 加载（可执行 JS），失败后降级为普通 HTTP 请求。

### 浏览模式

在订阅源列表中点击"打开"按钮，如果是浏览模式（`mode=browse`），自动打开独立窗口加载网页。

独立窗口顶部有自定义导航栏：后退、前进、刷新、URL 显示区、关闭按钮。

窗口支持下载检测：点击 `.json`、`.zip`、`.txt` 链接或 `yuedu://` 协议时，自动下载并识别资源类型（书源/订阅源/替换规则/目录规则），弹出确认对话框询问是否导入。

## 订阅源调试

入口：订阅源列表每行的"调试"按钮。

### 基本流程

1. 从顶部分类下拉框选择分类（如果订阅源配置了 `sortUrl`）
2. 在搜索框输入关键词或完整 URL
3. 点击"调试"执行
4. 左侧日志区域实时输出执行过程和结果
5. 解析完成后弹出结果窗口

### 日志

日志区域位于下半部分，实时滚动显示：

- 请求的完整 URL
- 获取到的 HTML 大小
- 列表规则的匹配元素数量
- 每条解析结果的标题和链接
- 错误和警告信息

可切换"详细日志"开关显示更底层的调试信息。

### 查看 HTML

弹出窗口以只读文本框展示获取到的完整 HTML 源码，显示字符数，支持复制。

### 解析结果

弹窗以列表形式展示解析出的文章：序号、标题（可点击跳转阅读）、链接。最多显示前 100 条，超出时提示总数。

## 订阅源编辑

入口：订阅源列表每行的"编辑"按钮，或新建订阅源。

编辑页面分为四个标签页，底部有快捷插入工具栏。

### 基础信息

- 名称、URL（必填）
- 图标 URL
- 分组（可从已有分组中选择，也可管理分组）
- 注释、变量说明
- 分类 URL（每行格式：`分类名::URL`）
- 搜索 URL（`{{key}}` 为关键词占位符）

### 开关选项

- 启用、单页源、保存 Cookie、预加载、优先缓存
- 启用 JS、基于 BaseURL 加载、输出 WebView 日志

### 类型与样式

- 类型：网页 / 图片 / 视频
- 文章样式：列表 / 卡片 / 网格2列 / 瀑布流 / 网格3列

### 列表规则

- 列表规则：CSS 选择器或 XPath
- 下一页规则：CSS 选择器或 `PAGE`
- 标题、链接、日期、描述、图片规则

### WebView 规则

- 正文规则
- 自定义样式
- 注入 JS
- 内容白名单/黑名单
- URL 跳转拦截

### 起始页

- 起始 HTML / CSS / JS
- 预注入 JS

### 网络与登录

- 请求头（JSON 格式）
- 并发率
- JS 库
- 登录 URL / UI / 检测 JS
- 封面解密 JS

### 快捷插入

- JS 代码块（`<js>`）

- 正则替换符（`##`）
- 逻辑连接符（`||`、`&&`、`%%`）
- put 映射（`@put:{`）
- 变量占位符（`{{}}`）

点击按钮后，语法片段插入到当前焦点所在的输入框或文本域的光标位置。

## 调试助手

入口：书源管理每行的"调试"按钮，或顶部菜单的"书源调试助手"。

顶部下拉框选择要调试的书源，六个标签页对应不同的调试功能。

### 搜索调试

输入关键词，点击搜索，查看该书源的搜索结果。显示书名、作者、URL。

### 目录调试

输入目录页 URL，点击获取目录，查看解析出的章节标题和 URL。

### 正文调试

输入章节 URL，点击获取正文，查看正文内容（显示前 2000 字符）。有"开始阅读"按钮可打开独立窗口渲染全文。

### JS 调试

编辑区输入 JS 代码，点击执行，结果区域显示返回值。

**预设测试模板：**

- **测试 base**：`toast` 和 `log` 基础输出
- **测试 ajax**：请求 httpbin.org
- **测试 base64**：编解码测试
- **全部测试**：综合测试 base64、MD5、时间格式化、UUID、ajax
- **测试 API**：简繁转换、UA、baseUrl

**重置上下文**：清空上次执行结果（`result` 变量），从头开始。

### WebView 调试

输入 URL 和可选的自定义 JS，设置超时时间，点击加载。使用系统 WebView 渲染页面并执行 JS，返回执行结果和耗时。

### 网络调试

输入 URL，选择是否使用 WebView，点击发送请求。显示 HTTP 状态码、耗时、响应头、响应体（前 5000 字符）。

### 编辑书源

点击"编辑书源"切换到 JSON 编辑器模式。顶部有返回按钮和保存按钮，下方为代码编辑区。可用的快捷输入助手（`keyboardAssists`）显示在工具栏下方，点击插入对应代码到光标位置。保存时校验 JSON 格式，格式错误给出提示。

### 日志

面板底部为全局日志区域，实时滚动显示所有模块的日志。可按模块和来源筛选，支持清空。

## 设置

### 外观

四种主题可选：深色、浅色、护眼、跟随系统。每个选项有预览缩略图，点击即切换。

### 阅读设置

- 字体大小：点击 `A-` / `A+` 按钮调整
- 行间距：点击 `-` / `+` 按钮调整
- 简繁转换：不转换 / 繁转简 / 简转繁
- 段落重排：开关，智能重排段落，修复错误分段

### 数据管理

**本地备份**

导出书架、书源、阅读进度、替换规则、分组、目录规则、字典规则等为 ZIP 文件。文件名格式：`backup2026-08-06-设备名.zip`

**本地恢复**

选择 ZIP 文件恢复数据。替换规则采用合并策略（追加不覆盖同名同规则），其他数据直接覆盖。

**缓存管理**

- 查看各类缓存的大小和文件数（封面、目录、正文、漫画、图片、JS 库）
- 点击各类别旁的"清理"按钮清理指定类别
- 调整缓存总上限（MB），保存后立即生效
- 迁移缓存目录：输入新路径，旧缓存文件自动移动过去。路径持久化保存，重启后仍在

**清空所有数据**

删除所有书籍、书源、规则和阅读进度，**不可恢复**。操作前建议先导出备份。

### WebDAV 同步

- 服务器地址、账号、密码、子文件夹（默认 `legado`）
- 设备名称：自动获取本机主机名，可手动修改
- 测试连接：PROPFIND 请求，207 表示成功，401 认证失败，404 文件夹不存在
- 上传备份：打包数据为 ZIP 上传
- 恢复备份：从备份列表选择恢复
- 刷新备份列表：重新获取服务器上的备份文件
- 配置变更自动保存（加密存储密码）

### 替换规则

正文净化规则管理：

- 添加/编辑规则：规则名称、作用范围（正文/标题）、匹配模式、替换内容、是否正则
- 每条规则卡片显示名称、作用范围标签、匹配和替换预览
- 开关切换启用/禁用
- 支持从 JSON、URL、文件导入规则

### TXT 目录规则

管理导入 TXT 时的章节识别正则规则。内置多组常见格式规则，可添加自定义规则。每条规则可启用/禁用。

### 字典规则

阅读器中选词查询的规则配置。添加规则需填写名称、请求 URL（`{{key}}` 为关键词占位符）、解析规则（CSS 选择器）。支持启用/禁用。

### User-Agent

设置书源网络请求使用的 UA。预设：移动端 Android（推荐）、桌面端 Windows、iOS iPhone、iPad、自定义。当前 UA 显示在文本域中可编辑，保存后立即生效，恢复默认回到移动端 UA。

### 诊断日志

查看 JS 执行的诊断信息，包括：

- 书源名称和 URL
- CryptoJS 是否加载
- 输入 HTML 长度、输出结果长度
- 解密缓存大小
- 结果预览（前 200 字符）
- 错误信息

日志自动从 Rust 后端收集，最多保留 50 条。支持复制全部和清空。
